# Datalogger

## API

### `POST /api/device/{device_id}/register`

Registers the caller-supplied device ID with the name `DEVICE_{device_id}`. Device IDs are never generated by the API. Attempting to register an existing ID returns `409 Conflict`.

### `POST /api/log/{device_id}`
Log data from device modules

```json
{
  "1720000000123": {
    "gps": "$GPGGA,...",
    "acc_x": 12,
    "acc_y": -4,
    "acc_z": 1020,
    "gyro_x": 1,
    "gyro_y": 0,
    "gyro_z": -1
  },
  "1720000000133": {
    "temperature": 23,
    "humidity": 54
  }
}
```

Supported fields are 
- `gps`
- `gyro_x`
- `gyro_y`
- `gyro_z`
- `acc_x`
- `acc_y`
- `acc_z`
- `temperature`
- `humidity`

## Integration test

With the API running on port `8000` and `RUN_ONLINE_TESTS` variable in `.env` file set to `1`, run:

```bash
pytest backend/tests
```
